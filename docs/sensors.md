
# Sensors

## Wiring
Sensors can be connected to the grove ports, however only the digital output is needed. If you use the grove ports, one of the GP pins could be used for another thing such as another sensor or switch, as long as it is able to get power.

## Programming
When value_when_pressed=False in the code for a sensor, the sensor will detect an object moving into view as event.pressed and an object moving out of view as event.released.
