
# Downloading and accessing files on the circuit board

## Connecting to the circuit board
There is a USB micro port on the circuit board that will be used to connect to the circuit board. When plugged in, the circuit board should appear as an external drive named "CIRCUITPY".

## Accessing files
You can directly access the files on this external drive for the circuit board. The file that will be used a lot is the code.py file, as accessing it in a code editor (such as Mu editor) will let you change the code on the board 

## Adding files
To add your own files such as .mp3 files for music or other libraries not pre-installed, download the files then copy them onto this external drive.
