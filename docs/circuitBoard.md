
# The Circuit Board

We are using Raspberry Pi Pico microcontroller boards, specifically [Cytron Maker Pi RP2040](https://www.cytron.io/p-maker-pi-rp2040-simplifying-robotics-with-raspberry-pi-rp2040) boards.



![Diagram of the circuit board](img/circuitBoardDiagram.png "Circuit Board Diagram")
![Photo of an actual circuit board](img/inPersonCircuitBoard.jpg "Actual Circuit Board")

## Notable parts
* On/Off Switch
* Vin Terminal (Green)
    * Where the cable for power will plug in
* 7 Grove ports
    * 3V3 = Power (3.3 volts)
    * GND = Ground
    * GP# = General Purpose Input or Output
* 4 Servo ports
    * + = Power (5 volts)
    * - = Ground
    * S = Signal (a GPIO pin)
* 2 Motor ports
* A Piezo Buzzer (sound and music) with mute switch
* 2 Buttons
* 13 Blue LEDs
* 2 NeoPixel LEDs
